# FF14Animus · 古武小黄书助手

适用于 **Omni Toolbox 本地模块**的古武书本助手。读取游戏进度，自动赶路、战斗、执行副本与理符，轮巡 FATE；本卷完成后前往摩杜纳换书。

**预览版 `0.1.0-preview.2`** · 作者 [Jhyxxxx1](https://github.com/Jhyxxxx1) · [问题反馈](https://github.com/Jhyxxxx1/FF14Animus/issues)

> 当前以白魔法师为主要实测职业。不按书本卷数限制执行，但九本书的所有特殊机制尚未全部验证。

## 下载与安装

1. 下载仓库中的 [AnimusBookAssistant.dll](https://github.com/Jhyxxxx1/FF14Animus/raw/refs/heads/main/AnimusBookAssistant.dll)，或下载 [完整预览包](downloads/FF14Animus-0.1.0-preview.2.zip?raw=true) 后解压到固定目录。
2. 在 Omni Toolbox 的 **插件设置 → 本地模块** 中添加 DLL，启用“古武小黄书助手”。
3. 更新时覆盖相同位置的 DLL，在本地模块列表中重新加载。请在脱战且任务交互结束后更新。

这是 Omni 的本地模块，无需单独添加卫月插件仓库。**正常使用不需要 Dalamud MCP**。

## 开始前

| 依赖 / 准备 | 用途 |
| --- | --- |
| Omni Toolbox | 加载本地模块 |
| vnavmesh | 地图导航、飞行与地面寻路 |
| AutoDuty | 副本路线与解除限制执行 |
| BossMod Reborn（BMR） | 自动输出、治疗与自动移动 |
| 对应职业的普通装备套装 | 从其他职业切换，不需要保存古武套装 |
| 当前书本对应的古武 | 放在背包或兵装库，模块会单独装备 |
| 基萨尔野菜 | FATE 战斗前召唤陆行鸟 |

打开模块，点击 **开始连续执行**。模块先切换对应职业、单独装备古武，并稳定核对实际装备，再推进当前书本。**停止**会结束本模块的执行；游戏已完成的进度不受影响。

## 界面与功能

- **当前任务与总进度**：显示运行阶段、当前动作和下一步。四个进度块可切换任务明细，窄窗口自动换为两列。未完成任务优先显示，已完成任务默认收起。
- **九本书总览**：按角色和古武分别保存“已完成、进行中、曾读取、未知”。只记录实际观测到的整本完成；未知不代表未完成，也不按当前卷数推断历史。
- **赶路设置**：优先坐骑、飞行，到目标附近再降落；实际飞行失败才回退地面。设置在重载后保留。
- **更多与排错**：版本、构建编号、依赖检查、书本读取恢复、附近目标信息。

### 连续执行规则

1. 依次执行书本怪物、副本、理符和 FATE。
2. FATE 传送后先扫描地图；一轮均未刷新时等待 5 分钟，期间继续扫描当前地图。战后立即重新巡查剩余目标。
3. 优先使用现有 BMR 输出 / AI 预设；没有预设时使用临时白魔输出和治疗配置，启用自动移动。离开本模块接管时恢复设置。
4. 战后检查敌对列表。残留 FATE 怪优先通过离开活动范围脱战处理，再继续其他任务。
5. 理符完成后确认返回集落 / 理符发行人；交付完成后再进入下一项。军票已满时仍确认领取报酬。
6. 目标理符未提供时，可执行已支持的备用理符刷新，最多 3 次，保留 1 次受理权。
7. **受理权为 0 时暂缓新理符**，先完成本书其他任务；已有可执行 / 可交付理符继续处理。其他任务完成后再停止，不提前换书。
8. 执行中死亡时暂停，角色复活后续行；缺古武时等待允许换装后自动补回。复活操作本身尚未全面自动化。
9. 本卷所有游戏完成标志齐全后，再自动前往摩杜纳换书。

## 支持范围

| 类型 | 当前支持 | 限制 |
| --- | --- | --- |
| 怪物 | 原生目标识别、跨地图击杀、遮挡检查 | 出生点数据和导航网格可能缺失 |
| 副本 | AutoDuty 已有路线的书本副本 | 无对应路线时停止并提示 |
| 普通理符 | 迎击、歼敌、防卫 | 按任务类型识别，不按卷数放行 |
| 特殊理符 | 已适配的焚书、巡逻、诱敌、索敌、警犬引导 | 其他特殊交互仍需新增策略 |
| FATE | 通用讨伐型及已适配特殊活动、前置活动 | 当前战斗配置仅支持白魔法师 |
| 自动躲避 | BMR 已识别的危险区域 | 不保证每种攻击均能识别或规避 |
| 历史书本 | 本功能启用后观测到的完成记录 | 无法可靠回读全部历史完成状态 |

前三卷及第三卷至第四卷换书已实测；第四卷已完成并换入第五卷。第五卷警犬引导已完成清路、跟随和续行验证，受理权用尽后继续 FATE 的分支已验证。**这不代表九卷全流程、所有职业和全部恢复分支都已通过测试。**

RSR、AE、WrathCombo 尚未接入。BMR 的部分集成使用经过字段检查的内部接口，插件升级后可能需要调整。

## 命令

| 命令 | 用途 |
| --- | --- |
| `/animusbook open` | 打开独立窗口 |
| `/animusbook auto` | 连续执行并自动换书 |
| `/animusbook stop` | 停止执行 |
| `/animusbook status` | 输出当前状态 |
| `/animusbook diagnose` | 检查依赖与副本路线 |

单项开发命令仍保留，普通使用无需操作测试入口。
