# 古武小黄书助手

适用于 Omni Toolbox 的本地模块。自动读取当前古武书本，显示任务进度，按怪物 → 副本 → 理符 → FATE 顺序执行；整卷完成后前往摩杜纳更换下一本书。

当前为持续调校中的预览版。第一、二卷已完成实测，第二卷到第三卷的自动换书已验证。第三卷及后续卷的特殊理符和 FATE 尚未完整适配，遇到不支持的任务会停止；请勿将本版视为九卷全自动版本。

## 安装

1. 安装并启用 Omni Toolbox、vnavmesh、AutoDuty 和 BossMod Reborn。
2. 将分享包解压到固定目录，在 Omni Toolbox 的“插件设置 → 本地模块”中添加 AnimusBookAssistant.dll，并启用“古武小黄书助手”。
3. 更新时替换同一位置的 DLL，然后点击本地模块条目右侧的重新加载。

本地模块不需要额外插件仓库，也不需要 Dalamud MCP。MCP 仅用于开发调试。

已使用的环境：Dalamud API 15、Omni Toolbox 1.1.8.0、vnavmesh 1.2.3.14、AutoDuty 0.0.0.352、BossMod Reborn 7.5.7.2。其他版本尚未逐一验证。

## 使用

装备当前书本对应的古武，准备好基萨尔野菜，在模块界面点击“开始连续执行”。“停止”结束本模块的连续执行，并清理本模块接管的移动、战斗和副本任务。已完成的书本进度由游戏保存。

主界面显示当前任务、本卷完成比例，以及怪物、副本、理符、FATE 四类明细。“赶路设置”控制坐骑和飞行；“更多与排错”提供独立窗口、依赖检查和读取恢复。

- 赶路优先坐骑和飞行，无法起飞或受阻时回退地面；骑乘地面受阻后尝试下坐骑步行。
- 战斗交给 BMR，优先使用现有输出或 AI 预设；没有预设时使用临时白魔输出和治疗配置。启用自动移动，离开战斗接管时恢复设置。RSR、AE、WrathCombo 尚未接入。
- BMR 只会躲避其能识别的危险区域；自动躲避与 FATE 撤离仍待更多场景验证。
- 当前 FATE 执行只支持第一、二卷白魔法师。传送后扫描当前地图；一轮都未刷新时等 5 分钟，等待期间仍扫描本地图，战后立即重新巡查。
- 书本所需击杀完成后，如仍有 FATE 怪追击，会尝试停止攻击、退出同步并离开活动范围脱战，不等待整场 FATE 结束。
- 理符完成后自动确认返回集落；军票已满时仍确认领取报酬。缺少目标理符时可用备用理符刷新，最多 3 次并保留 1 次受理权。

## 常用命令

- `/animusbook open`：打开独立窗口。
- `/animusbook auto`：开始连续执行并自动换书。
- `/animusbook stop`：停止执行。
- `/animusbook status`：输出当前状态。
- `/animusbook diagnose`：检查依赖与副本路线。

单项调试命令仍保留供排错使用，主界面不再显示测试按钮。

## 排错与反馈

无法开始时查看界面中的装备或角色状态提示；导航、依赖异常时展开“更多与排错”。反馈时附上当前书名、任务名、界面状态和发生位置即可。

开发构建使用 build.ps1；Get-ModuleStatus.ps1 -VerifyBuild 可核对实际加载版本。详细实测记录见 BOOK1-VERIFICATION.md，数据来源与署名见 DATA-SOURCES.md。分享包包含模块 DLL、对应源码、使用说明和数据来源，不包含第三方插件程序。
